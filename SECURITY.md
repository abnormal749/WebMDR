# Security policy

WebMDR is a static page with access to Bluetooth headphones the user has authorized. Security problems include anything that lets a page, script or other party send commands to headphones without the user's action, bypass the content-security policy, or leak data from the page.

## Reporting

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Don't open a public issue for them.

Include the build id from the page footer, the browser and OS, and steps to reproduce. You'll get a reply as soon as the maintainer can; this is a volunteer project with no fixed response time.

## Supported versions

Only the latest build on `main`, as deployed to https://abnormal749.github.io/WebMDR/, receives fixes.
